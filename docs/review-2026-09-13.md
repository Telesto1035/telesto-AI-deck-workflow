## 2. The diff against comments

**Before.** Comments were read by the model unzipping XML by hand, the Revise log was typed from memory, and the ledger rows were typed by hand. `deck_diff.py` listed 26 appendix slides as "moved" on the EDR pair, drowning the body changes.

**Now.**
- `deck-qc/scripts/pptx_comments.py DECK.pptx` lists every comment with slide number (from the slide relationships, in presentation order), author (from `authors.xml` or `commentAuthors.xml`), date, status, anchored shape and replies. Both formats: modern (2019+/365) and legacy (2007-2016). `--open-only` skips resolved ones. `--resolve all|3,5 --out FILE` marks modern comments resolved in a copy, touching nothing else in the package. Run on the EDR v2 deck it returned the same 11 comments the ledger records, with the one Fiona comment correctly shown as resolved.
- `scripts/deck_diff.py BEFORE AFTER --comments --ledger-rows` joins each comment in BEFORE to the content changes on its slide (or says "slide removed" / "no change on this slide") and prints ledger rows with class and resolution left blank for the consultant. Appendix pages are reported as one count line unless `--all`. The number regex no longer treats a sentence's full stop as a number change.
- The step that remains human: classing each comment (mechanical, judgment, ambiguous) and writing the resolution. Those are judgment; the skeleton removes the transcription.
